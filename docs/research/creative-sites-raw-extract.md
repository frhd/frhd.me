### ?
- The signature feature of cassie.codes was an interactive animated SVG self-portrait ('lil me') on the homepage that responds to the visitor's cursor position, and Evans explicitly frames interactivity — not motion per se — as what makes web animation on a personal site special, a philosophy directly applicable to a playful personal-site redesign.
- Evans built all SVG animation on her site with GreenSock (GSAP), chosen specifically because browsers implement the SVG spec inconsistently and GSAP normalizes cross-browser behavior — a concrete tooling recommendation for anyone adding SVG character animation to a personal site.
- The transferable implementation recipe: map mouse clientX/clientY into a centered -50..50 range (via gsap.utils.mapRange or manual percentage math), drive transforms inside a requestAnimationFrame/gsap.ticker loop, skip recomputation when the cursor hasn't moved, and use gsap.quickSetter for high-frequency updates, which she says boosts performance roughly 50-250%.
